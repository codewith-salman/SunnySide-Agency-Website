## 📖 About The Project

<img src="SunnySide%20Agency%20Website/images/desktop.png" alt="SunnySide Agency Website Screenshot" width="100%" />

The **SunnySide Agency Website** is a vibrant and professional UI concept designed for creative agencies, digital studios, and marketing teams.

The project focuses on:
- Strong storytelling through layout  
- Clear content hierarchy  
- Bold visuals and typography  
- Fully responsive design  

This project is ideal for:
- Creative and marketing agencies  
- Digital studios and startups  
- Business landing pages  
- Agency portfolio websites  
- UI/UX design practice  

This is a **front-end only project**, created for learning, UI practice, and portfolio showcasing — no backend integration included.
